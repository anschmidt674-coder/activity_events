jQuery Selectors Used

#clickButton
This ID selector selects the button with the ID "clickButton". It is used to add the click event.
#clickText
This ID selector selects the paragraph with the ID "clickText". It is used to change the text when the button is clicked.
#doubleClickText
This ID selector selects the paragraph with the ID "doubleClickText". It is used to add the double-click event.
#hoverButton
This ID selector selects the button with the ID "hoverButton". It is used to add the hover event.
